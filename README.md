# Evidencia SENA: Git y GitHub

Proyecto pequeño para practicar el control de versiones local con Git y la publicación de cambios en un repositorio remoto de GitHub.

## Aplicación

`contador.py` es un contador interactivo de consola. Permite incrementar el valor y salir de la aplicación.

## Requisitos

- Python 3
- Git
- Una cuenta de GitHub

## Ejecución

Desde esta carpeta, ejecuta:

    python contador.py

## Práctica de versionamiento

1. Inicializar un repositorio local con Git.
2. Registrar una primera versión del proyecto.
3. Realizar un cambio en la aplicación o en este README y registrar otra versión.
4. Crear un repositorio remoto en GitHub.
5. Conectar el repositorio local con el remoto y publicar los cambios.
6. Verificar el historial de versiones y la sincronización entre ambos repositorios.
